# Ocean Surf Camp: first screen

Concept hero for a one-week surf camp for beginners. On load the photo zooms out, "CATCH YOUR" rises and "FIRST WAVE" slides up word by word. Then a liquid wave runs from the surfer through the headline (WebGL2). Move the cursor over the screen to push the water yourself; after a few idle seconds the wave runs again.

Everything lives in `index.html` (Inter font and all images are inlined), so it deploys as a static site.
